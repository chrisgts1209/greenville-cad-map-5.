GREENVILLE CAD MAP — GITHUB PAGES DEPLOYMENT

This folder is prepared for static hosting. The viewer uses relative paths,
so keep the folder structure intact:
- index.html
- map_background.png
- data/*.geojson

PUBLISH WITH GITHUB PAGES (FREE FOR PUBLIC REPOSITORIES)
1. Sign in to GitHub using an account you control.
2. Create a new repository named greenville-cad-map.
   If you want the published site publicly accessible, make the repository public.
3. Upload the contents of this ZIP to the repository root. Do not upload the ZIP
   itself as the only repository file; upload/extract its contents.
4. Open the repository's Settings > Pages.
5. Under Build and deployment, choose "Deploy from a branch".
6. Select branch "main" and folder "/ (root)", then Save.
7. Wait for GitHub Pages to publish. The site URL will appear in Settings > Pages.
8. Share that URL in your Discord.

UPDATING THE MAP
Edit the project files locally, then upload/commit the changed files to the same
repository. GitHub Pages will publish the update automatically after deployment.
